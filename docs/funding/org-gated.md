# Entity registration — what it unlocks, and the defer decision

## Current answer: defer

No priority lane requires a registered entity:
- Stellar SCF — projects/teams welcome
- World Foundation — builders/teams
- Filecoin FF — individuals + repos
- Octant / Giveth / ESP — individuals
- Prezenti — individual/team

Registration only gates programs that are **currently closed anyway** (UNICEF VF next cycle, Mercy Corps C4G V, Climate Collective cohorts, Global Innovation Lab). Registering now burns setup cost into a hypothetical — better spent on the live lanes.

## What registration would unlock (for when a call goes live)

| Program | Requires | Typical award |
|---|---|---|
| UNICEF Venture Fund | registered startup in a UNICEF programme country | up to $100k equity-free |
| Mercy Corps Crypto for Good | registered entity | pilot grants + TA |
| Climate Collective accelerators | registered entity preferred | $20–50k non-dilutive |
| Global Innovation Lab | institution-backed instruments | program funding, not equity |
| Sovereign Tech | any (incl. individuals) but criticality bar | varies |

## If/when registering

- **UK Ltd** is the cheapest credible option (user is UK-adjacent for the hackathon; Hackagodot/ResponsibleRisk context) — Companies House, ~£50, one-day formation. Not a nonprofit, but grants accept Ltds for most of these programs.
- **Fiscal sponsor alternative**: Open Collective Foundation-style hosts take % of grants but zero formation cost — viable if a grant lands before registration.
- **Wallet + bank readiness**: a registered entity needs a receiving address/bank for grant disbursement — Gnosis Safe on Celo is the natural fit (safe.global) given the existing Celo rails.

## Trigger to revisit
Any of: a live org-gated call reopening, a grant offer requiring an entity, or earning >£1k/mo equivalent revenue through the protocol (skim/endowment accounting becomes real).
