# Demo script — ~4 minutes

Base: https://springforth.widespread.workers.dev

1. **Landing** (/) — "coordinate first" + what needs attention: open cards,
   unmet needs, machine-flagged overlaps awaiting humans. 30s.
2. **Possibilities** (/possibilities) — the deck: Mida Creek hero card
   (4/6 committed), flood-response prep (live EA dataset context), dance
   night (partial, names masked until critical mass), completed Kwale card
   with its report. 45s.
3. **Outcomes** (/outcomes) — the reveal: *"Restored mangrove cover…" —
   4 pursuing this outcome*: Kilifi County, the community plan, and
   **Treegens' real filmed plots at Kisiwani + Dabaso**. 60s.
4. **Coordination** (/coordination) — overlap evidence/counter-evidence
   tables, validation form (separate / coordinate / combine), complements
   section = needs met by community offers, then the unmet-needs open asks.
   60s.
5. **Verify** (/verify) — open-evidence readings per target node:
   Sentinel-2/GBIF/Treegens/NASA baselines for the Mida action + Treegens
   records. Human review stays authoritative. 30s.
6. **Trust + metrics** (/trust, /metrics) — mutual-recognition edges,
   earned recognition, quorum rate, appreciation ratio. 30s.
7. **Ledger** (/ledger/verify) — hash-chain verify; mention the
   OpenTimestamps Bitcoin anchor at /ledger/anchor. 15s.

Telegram lane (optional +30s): /new declares a card from a group chat;
quorum announcements post back to the declaring group.
